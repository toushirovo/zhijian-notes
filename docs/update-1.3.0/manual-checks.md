# 1.3.0 手工验收

请保存并关闭旧版，运行 publish/win-x64-1.3.0/zhijian.app.exe。建议在独立测试工作区操作。

1. 新建两篇笔记。在第一篇“更多”中点击“置顶笔记”，即使第二篇刚保存，第一篇仍排在顶部。再取消置顶，应恢复按更新时间排列。
2. 在“更多”收藏其中一篇，左侧打开“我的收藏”，只显示该篇。搜索其正文并选择标签，确认筛选有效。取消收藏后从收藏列表消失。
3. 收藏并置顶一篇笔记，移到回收站后恢复，检查两种标记仍在。关闭并重新打开工作区，再检查标记。完整备份恢复后也应保留。
4. 从资源管理器拖入一张PNG/JPEG到正文，确认显示并自动保存。可一次拖多张。将原图移动到别处后重新打开笔记，图片仍显示。
5. Win+Shift+S截图后点击正文并按Ctrl+V。复制一段普通文字后Ctrl+V，应正常插入文字。复制图片文件后Ctrl+V，应插入图片。
6. 点击右侧图片，拖动滑块放大。在下拉框选择“小图 · 240”并应用，预览图片变小。Ctrl+Z应撤销尺寸修改。再选择大图或自适应，确认不超过预览区域宽度。
7. 将含尺寸设置的笔记导出，并把Markdown与assets一起导入测试工作区，检查图片仍能显示。回收站图片可打开查看，但没有“应用显示尺寸”操作。
8. 拖动笔记列表右边的竖线，再拖编辑与预览之间的竖线。切换仅预览后返回分屏，比例应保持。关闭重开同一工作区应保持宽度；另一工作区使用自己的布局。
9. 切换深色主题，将窗口缩小到1100×700，检查功能入口可访问。笔记较多时仍可滚动列表。
