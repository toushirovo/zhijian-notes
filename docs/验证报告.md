# 知笺 V1.0 实现验证

验证日期：2026-10-24。结果来自本次代码的实际执行，不引用需求文档中的模拟访谈或原型成绩。

## 环境

- Windows 11 家庭版 中文版，64 位，版本 10.0.26200。
- Intel Core i9-13980HX，24 核、32 逻辑处理器，约 16 GiB 内存。
- .NET SDK 10.0.402；项目目标 net10.0-windows。
- Markdig 0.37.0；Microsoft.Data.Sqlite 10.0.13；SQLitePCLRaw 2.1.13。
- 测试数据位于项目 artifacts 下的独立目录，没有读取或改写用户笔记。

## 自动化功能检查

Core 集成检查 38/38 通过，明细在 checks.txt。涵盖工作区独占、Unicode 输入边界、重复标签、精确搜索及 SQL 特殊字符、修订冲突、正文超限、双链去重、代码块排除、重命名、删除恢复、批量导入部分失败、编码校验、UUID/相对链接重映射、格式化及引用式链接迁移、完整备份恢复、非空目标保护、备份篡改及路径穿越、索引重建、分页失效、损坏记录隔离、正文校验和备份取消。

保存可靠性检查包括真实子进程在 dirty 标记后、正文写入后、记录提交后三个位置直接退出。重开后分别读取到正确的完整版本，索引自动追平。另用真实文件共享锁阻止记录替换，确认失败后旧版本仍可读，并可重试成功。这些检查不等同于硬件断电测试。

WPF 窗口在独立测试模式实际启动，8/8 检查通过：两秒自动保存、双链索引、界面搜索、反向引用、回收站只读、恢复、主题设置、安全预览。保存测试等待计时器完成，没有手动保存兜底。浅色、深色和最小窗口布局已生成 PNG 并检查。UI 测试通过内部事件流程驱动真实控件，不是人工鼠标/键盘完整验收。

NuGet 漏洞查询对三个项目及传递依赖均未报告当前已知漏洞；这不是对未来漏洞或整个程序安全性的保证。

## 性能实测

生成 5,000 篇笔记，正文合计 98,983,890 字节（94.40 MiB），20,000 条引用。搜索、读取、保存、工作区打开各测 30 次；P95 为升序第 29 项。逐次数据见 performance.json。

| 项目 | 本机实测 |
| --- | ---: |
| 首次打开并重建全部索引 | 1,969.0 ms |
| 工作区打开 P95 | 529.1 ms |
| 精确子串搜索 P95 | 83.2 ms |
| 读取并校验正文 P95 | 0.2 ms |
| 保存及同步更新索引 P95 | 41.7 ms |

这些是 Core 服务层测量，使用热文件系统缓存，不包含 WPF 首屏绘制、输入防抖、搜索结果渲染等端到端耗时；重建只记录一次整体测量。硬件高于文档的四核/8 GB 基准，不能将这些数字直接标记为原基准环境的 NFR 全部验收通过。

## 仍需人工课程验收

- 五名真实首次使用者完成指定任务链；不能以自动化测试代替。
- 指定四核/8 GB/SSD 环境下的完整应用冷启动、热启动和界面响应测量。
- 150%/200% 系统显示缩放、屏幕阅读器和人工键盘焦点走查。
- 物理磁盘写满、运行中 ACL 撤销、移动介质拔出和硬件断电。
- 在断网条件下人工走完原 AC-01～AC-13；本实现没有核心联网依赖，但未通过改变用户电脑网络配置来进行这项验收。

## 设计蓝图与本版差异

采用独立 Core + WPF UI，核心文件格式、稳定 UUID、不可变正文、原子记录更新和可重建索引与设计保持一致。为使课程版本可读、可运行，Core 用进程内串行锁协调操作；备份/导出/重建时暂时阻止编辑，并显示进度和取消入口。并未实现完整的持久任务协议、跨重启请求幂等、后台差异追平、外部确认令牌接口和恢复候选向导。

本报告说明已实现和已验证的范围，不宣称所有设计章节或全部 NFR 已完成正式验收。


## 关闭窗口修复

修复 Closing 事件中同步重入 Close 导致的 InvalidOperationException。关闭操作现在先取消当前关闭事件，待事件返回后再执行保存确认和最终关闭，并防止重复请求。新增空工作区重复关闭、已保存工作区正常关闭检查，均通过；原 8 项界面检查仍通过。双链选择器明确设置列表项样式以减少默认祖先绑定提示。
