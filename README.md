# 知笺

面向学生与知识工作者的本地优先 Markdown 桌面笔记工具。Windows 11 x64，C# / WPF / .NET 10。

## 运行

已发布程序位于 `publish/win-x64/zhijian.app.exe`。双击即可运行；请保留整个发布目录，不能只复制 exe。自包含发布包已附带 .NET 运行时，使用者无需另外安装 SDK。

首次运行点击右上角“新建工作区”，选择一个空的本地文件夹。例如 `D:\我的知笺笔记`。已有工作区可直接打开。程序记住上次打开位置，配置保存在 `%LOCALAPPDATA%\Zhijian\last-workspace.txt`。

## 在 Visual Studio 中继续开发

打开根目录 `zhijian.slnx`，或原来的 `zhijian.app/zhijian.app.slnx`。两个解决方案均包含三个项目。右击 `zhijian.app` → 设为启动项目 → F5。若 Visual Studio 提示文件在外部发生变化，选择重新加载。

安装 .NET 10 SDK 10.0.402 或兼容更新补丁。首次还原 NuGet 包需要联网；构建完成后的笔记功能离线可用。

```powershell
dotnet build .\zhijian.slnx -c Release
dotnet run --project .\zhijian.app\zhijian.app.csproj
```

可使用 `build.ps1 -Check -Publish` 执行依赖锁定还原、构建、回归检查与发布。依赖版本和内容摘要记录在各项目的 `packages.lock.json`。

## 已实现

- 工作区创建、打开、切换和独占锁。
- 新建、编辑、重命名；停止编辑两秒自动保存及 Ctrl+S；失败保留编辑内容。
- Markdown 基础语法预览；脚本不执行，远程图片不加载。
- 标签去重、多标签交集、标题与正文的字面子串搜索、摘要和分页。
- 通过选择器插入 `note:UUID` 双链、反向引用、失效目标提示。
- 回收站、恢复、永久删除和清空确认。
- UTF-8 Markdown 批量导入、新 ID 与批内链接映射；单篇和全部导出及报告。
- 含回收站和设置的完整目录备份、逐文件 SHA-256 校验、恢复到新空目录。
- 可重建 SQLite 索引、异常退出恢复、正文完整性校验。
- 浅色/深色主题、快捷键、离线帮助。

## 项目结构

| 路径 | 责任 |
| --- | --- |
| zhijian.app | WPF 界面、对话框、编辑状态、安全 FlowDocument 渲染 |
| Zhijian.Core/Models.cs | 数据模型与输入规则 |
| Zhijian.Core/Workspace.cs | 工作区、不可变正文、原子元数据提交、回收站 |
| Zhijian.Core/NoteIndex.cs | SQLite 派生索引与参数化搜索 |
| Zhijian.Core/MarkdownLinks.cs | 基于 Markdown AST 的链接提取和重写 |
| Zhijian.Core/Transfer.cs | 导入、导出、备份清单与恢复 |
| Zhijian.Core/Disk.cs | 持久化写入、原子替换、路径检查 |
| Zhijian.Checks | 无需测试框架的真实文件系统集成检查、进程退出注入、性能数据生成 |

权威数据在 `records/<UUID>.json` 与 `bodies/<UUID>/<版本>.md`；SQLite 仅为可重建索引。先完成正文写入和刷新，再原子切换记录指针，避免正文与元数据只更新一半。删除以状态表达，恢复保留 UUID。

## 使用与数据边界

工作区请放在可写的本地目录，按设计在 Windows 11 / NTFS 环境使用。运行期间不要用外部编辑器改动内部文件，不使用网络盘、目录联接或正在同步的云盘目录。不要将导出或备份放在当前工作区内部。

普通导出仅迁移 Markdown 正文；标签、回收站、设置须使用完整备份。备份为普通目录包，不是 ZIP。将整个 `backup-...` 目录复制到其他介质即可保存。恢复失败时保留 `restore-incomplete` 标记并阻止普通打开，可另选空目录重试。旧备份可能保留后来删除的笔记。

本版不含云同步、移动端、多人协作、插件市场、PDF/Word 导出和可浏览的历史版本。内部提交保护文件不是用户可见的版本历史。

## 验证与实现说明

`docs/验证报告.md` 记录实际验证结果及尚需人工完成的课程验收。文档中的原型分数和模拟访谈不作为软件实测证据。

相较设计文档的完整接口蓝图，本次可运行版本使用同步 Core 服务，由 WPF 在线程池调用；迁移和重建期间显示可取消的任务层，暂停界面编辑，保证一致性。未引入跨服务 requestId 幂等缓存、持久任务轮询和故障现场恢复候选向导；损坏对象会保留并提示从备份恢复。永久删除采用用户确认及修订号复核，未提供对外调用的确认令牌协议。分页通过代次检查防止过期列表继续加载。

这是一版可运行、可继续开发的课程项目实现。硬件断电、磁盘写满/ACL 撤销、五名真实用户任务测试，以及 150%/200% 系统缩放仍需按课程要求单独验收。程序没有联网笔记服务或遥测代码；外部网页只在用户点击确认后由默认浏览器打开。
